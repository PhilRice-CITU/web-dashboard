# Analytics

The **Analytics** page summarizes grading activity across your region.

## What the charts show

- **Grade distribution** — the mix of quality grades over the selected period.
- **Defect rates** — how often each defect type appears.
- **Throughput** — how many scans were graded over time.

## Using analytics

Use these trends to spot changes in incoming rice quality, compare devices, and
confirm that throughput matches expected milling volume. For the meaning of each
grade and defect, see [Grading & standards](/docs/grading-and-standards/how-grading-works).
