The **Devices** page lists the Raspberry Pi edge units registered to your region.

## Device status

Each device reports a live status. A device is **online** while it sends regular
heartbeats and **offline** when heartbeats stop. Use this to confirm a rig is
reachable before expecting new scans.

## Provisioning a device

A new edge unit is registered by provisioning it, which issues the device its
credentials. Once provisioned, the device authenticates with hum.ai on every
upload — no user login is involved on the device side.

## Monitoring

Open a device to see its recent activity and event log. Investigate any device
that has been offline unexpectedly or is reporting errors.
