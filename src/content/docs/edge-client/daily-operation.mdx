# Daily operation

## The kiosk screens

- **Splash** — shown briefly at startup while the device loads.
- **Home** — the main screen, where you start a new scanning session.
- **Session** — the captured images for one scanning session, with the
  **Submit** button.

## Capturing a scan

1. Place the rice sample on the device.
2. Press the physical **capture button** (or the on-screen capture button).
3. The device takes two photos — one under infrared, one under the white LED —
   and the **Session** screen shows them for review.
4. Check the photos, then tap **Submit**.
5. The images upload to hum.ai for grading.

## If an upload fails

The device uploads each scan as soon as you tap **Submit**. When the upload
succeeds it shows an **Upload Sent** confirmation. If it fails — usually
because of a network problem — the device shows an error message; check the
connection and tap **Submit** again to retry.

<Callout>
  Once a scan is graded, its result appears in the hum.ai dashboard under
  Results.
</Callout>

To change the device's API settings or run mode, see
[Configuration & modes](/docs/edge-client/configuration).
