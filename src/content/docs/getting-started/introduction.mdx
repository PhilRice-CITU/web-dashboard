# Introduction

**hum.ai** is the Rice Analytics dashboard for an automated rice quality grading
system compliant with **PNS/BAFS 290:2025**. Edge devices capture milled-rice
scans; hum.ai grades them and surfaces the results here.

## What this guide covers

This documentation has two parts. The **operator guide** explains how to use the
dashboard day to day — reviewing results, managing devices, and reading analytics.
The **technical reference** documents the API, database, and grading pipeline for
developers.

## Getting started

If this is your first time, read [Dashboard overview](/docs/getting-started/dashboard-overview)
to learn the layout, then [How grading works](/docs/grading-and-standards/how-grading-works)
to understand the PNS quality grades.
