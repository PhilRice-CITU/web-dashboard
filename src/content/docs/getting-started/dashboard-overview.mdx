# Dashboard overview

The hum.ai dashboard is organized around a left sidebar. Each item opens a
workspace for one part of the rice-grading workflow.

## Main sections

- **Results** — a reverse-chronological feed of graded rice scans.
- **Devices** — the Raspberry Pi edge units registered to your region.
- **Analytics** — charts summarizing grades, defects, and throughput.
- **Test Grading** — grade a sample image manually, without an edge device.

## Regions

Data in hum.ai is scoped by region. Admins see only their assigned region;
superadmins see every region. Your role and region are set when your account is
created — see [First login & roles](/docs/getting-started/first-login-and-roles).

<Callout>
  New scans appear in **Results** automatically as edge devices upload them — no
  refresh needed.
</Callout>
